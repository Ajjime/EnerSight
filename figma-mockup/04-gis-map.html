Accessibility notes — GIS Map

  1. 1Map, list, or both. A map can't be "seen" by a screen reader, so the same information is always available as a plain list. Blind users can choose "List only".
  2. 2Full keyboard control. Arrow keys pan, +/− zoom, and Tab jumps between buildings. The shortcuts are shown on the map, so no one has to guess them. Zoom buttons are 48 × 48 px.
  3. 3Pin shape = status. Circle, triangle, octagon, dashed circle. Colour-blind users can tell Critical from Normal by shape alone. Labels have a white outline so they stay readable over the map.
  4. 4Linked selection. Selecting a building in the list highlights its pin (blue dashed ring) and opens the same popup, so the map and list never disagree.
