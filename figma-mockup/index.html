EnerSight

Accessible System Mock-up

EnerSight is a campus building energy monitoring system with meter-photo OCR, EUI status grading, a GIS map, analytics, forecasts and printable reports. This prototype shows how each screen supports users with accessibility needs. Purple numbered pins mark each accessibility feature and are explained under every screen.

Who this design supports

👁 Low visionText size A/A+/A++, high contrast, read aloud, large print reports
🎨 Colour blindnessEvery status has a shape + word, striped bars, colour-blind palette
⌨ Blind / keyboard usersSkip link, focus ring, map list view, data tables, alt text
✋ Motor disabilities44px+ targets, voice input, manual entry, longer timeouts
🧠 Cognitive & languagePlain-language summaries, step indicator, Cebuano, error prevention
