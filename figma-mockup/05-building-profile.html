What does this mean? 2

EUI compares a building's yearly energy use with its size, so big and small buildings can be compared fairly. This building uses almost twice what is considered normal. Common causes: air-conditioners running after class hours, old lab equipment, lights left on.

Accessibility notes — Building Profile

  1. 1The number comes first, then the scale. The meter bar has zone labels with symbols (✓ ▲ ✕) and a full text value for screen readers (role="meter", aria-valuetext).
  2. 2"What does this mean?" is an expandable explanation in everyday words. It's a native <details>, so it works with keyboard and screen readers without extra code.
  3. 3Proper data tables. Captions, column and row headers (scope) and right-aligned numbers let screen readers announce "Measured, kWh per month, 4,210".
  4. 4Data-table view shown. Every chart can switch to a table. Change is written with ▲/▼ and a percentage. Forecast rows are labelled "Forecast" in words, not only with a dotted line.
  5. 5Large-print report and CSV. Users with low vision can print at a bigger size. Screen-reader users can open the CSV in a spreadsheet they already know how to use.
