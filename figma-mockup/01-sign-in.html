Accessibility notes — Sign In

  1. 1Accessibility toolbar before login. Text size (A / A+ / A++), high contrast and English/Cebuano can be set before signing in, so low-vision users are not blocked at the first screen.
  2. 2Errors use text + icon, not only red. The message explains what went wrong and how to fix it, and is announced by screen readers (role="alert").
  3. 3Visible labels + show password. Labels never disappear like placeholders. "Show" helps users with motor or memory difficulties check what they typed. The error is linked to the field (aria-describedby).
  4. 4Large target + visible focus ring. Buttons are at least 44px tall. The blue 3px ring shows keyboard users where they are (shown here on "Sign in").
